# 凪の島 — NAGI

淡く物悲しい瀬戸内の小さな島を歩く、一人称探索RPGの基本セットです。依存パッケージや外部CDNは使いません。WebGL対応のブラウザで動作します。

## 起動

```sh
python3 -m http.server 4173 --directory dist
```

ブラウザで `http://localhost:4173` を開き、「島へ渡る」または Enter で開始します。

## 操作

- W / S（↑ / ↓）：前進 / 後退。後退時も同じ向きを保ちます。
- A / D：左右のカニ歩き。
- ← / → または Q / E：水平旋回。
- Shift：少し速く歩く。
- マウス / タッチ：画面を押し続けて移動。画面上側で前進、下側で後退。左右中央寄りはカニ歩き、左右端へ近づくほど旋回に滑らかに変化します。指やマウスを離すと停止します。
- Escape / フォーカスを外す：入力を解除。

視線の上下操作・頭の揺れ・照準・移動ボタン・プレイ中のメニューはありません。島民に近づくと自動で挨拶します。音は開始操作の後に小さく流れます。

## 島の構成

オリーブの小径、潮見の鳥居、丘の祠、干潮の砂州、小さな離れ島。能を思わせる面と衣をまとった4人の島民、淡い色の縞模様のキノコ、巻いたシダ。地形は小豆島と瀬戸内から着想した架空の島です。

## 構造

- `dist/index.html`：開始画面と地名・挨拶の字幕。
- `dist/style.css`：全画面表示、淡い和文組版、開始後のUI非表示。
- `dist/island.js`：WebGL描画、手続き生成モデル、入力、衝突、島民、環境音。
- `dist/terrain.js`：地形と操作グラデーション。
- `tests/terrain.test.js`：地形の接続・操作の数学的な検証。
- `tests/browser-check.py`：Playwrightでの起動・移動・UI確認（任意、PlaywrightとChromiumが必要）。

```sh
npm run check
```

現段階は島を歩く基本セットです。戦闘、クエスト、セーブ機能はまだありません。

## GitHub Pages / iPhone で遊ぶ

- 公開URL: https://hane-san.github.io/Koitototsukuru/ （起動時に `dist/index.html` へ移動）
- iPhone の Safari で共有 → ホーム画面に追加を選ぶと、能面アイコン「凪の島」として保存できます。アイコンは `assets/nagi-icon-120.png`。
- `manifest.webmanifest` に起動URLとアイコンを登録済みです。
- Service Worker による固定キャッシュは作らず、毎回の起動で CSS とゲーム JS（地形 JS 含む）のURLに変化をつけ、以前の版を使い続けないようにしています。公開CDNの配信反映には数分かかる場合があります。すでに開いている画面は閉じて再度開いてください。
- GitHub Pages が `main / (root)` に設定されていれば、main の更新は自動公開されます。Codexなどの作業ブランチだけを編集しても公開されず、mainへのPRマージが必要です。
