# 凪の島 — NAGI

淡く物悲しい瀬戸内の小さな島を歩く、一人称探索RPGの基本セットです。依存パッケージや外部CDNは使いません。WebGL対応のブラウザで動作します。

## 起動

```sh
python3 -m http.server 4173 --directory dist
```

ブラウザで `http://localhost:4173` を開き、「島へ渡る」または Enter で開始します。

## 操作

- W / S（↑ / ↓）：前進 / 後退。後退時も同じ向きを保ちます。
- A / D：左右のカニ歩き。
- ← / → または Q / E：水平旋回。
- Shift：通常の走りから、さらに少し加速。
- マウス / タッチ：画面の下半分に指を置き、そこから上へスライドすると前進（通常で秒速7.8の走り）。下へスライドで後退、左右へのスライドは旋回、斜めへのスライドは曲がりながらの前進・後退になります。横へ動かした際にカニ歩きへ切り替わる動作はありません。置いただけでは移動せず、指を離すとすぐ停止します。スライド量で速度を調整できます。
- Escape / フォーカスを外す：入力を解除。

視線の上下操作・頭の揺れ・照準・移動ボタン・プレイ中のメニューはありません。島民に近づくと自動で挨拶します。音は開始操作の後に小さく流れます。足音は実際に進んだ距離と速度に合わせて交互に鳴り、砂・草・石で質感が変わります。停止・その場での旋回・障害物に押しつけた状態では足音は鳴りません。

## 島の構成

オリーブの小径、潮見の鳥居、丘の祠、干潮の砂州、小さな離れ島に加え、北側へ薄紫の傘の森、花の尾根道、オリーブの段々畑、硝子の入江、空に近い岬を広げました。元の浜から北を一周して戻れる道と、入江への寄り道があります。能を思わせる面と衣をまとった7人の島民、淡い色の縞模様のキノコ、巻いたシダ、傘の形の大きな植物。地形は小豆島と瀬戸内から着想した架空の島です。

## 構造

- `dist/index.html`：開始画面と地名・挨拶の字幕。
- `dist/style.css`：全画面表示、淡い和文組版、開始後のUI非表示。
- `dist/island.js`：WebGL描画、手続き生成モデル、入力、衝突、島民、環境音。
- `dist/terrain.js`：地形・周回路・地名・一本指入力・接触時の滑り。
- `tests/terrain.test.js`：地形の接続・操作の数学的な検証。
- `tests/world-check.py`：北側の周回と入江への寄り道、配置物への衝突・景色の描画を検証。QA用アクセスは検証中のローカル応答にだけ挿入し、ゲームには含めません。
- `tests/browser-check.py`：Playwrightでの起動・移動・UI確認（任意、PlaywrightとChromiumが必要）。

```sh
npm run check
```

現段階は島を歩く基本セットです。戦闘、クエスト、セーブ機能はまだありません。

## GitHub Pages / iPhone で遊ぶ

- 公開URL: https://hane-san.github.io/Koitototsukuru/ （起動時に `dist/index.html` へ移動）
- iPhone の Safari で共有 → ホーム画面に追加を選ぶと、能面アイコン「凪の島」として保存できます。アイコンは `assets/nagi-icon-120.png`。
- `manifest.webmanifest` に起動URLとアイコンを登録済みです。
- Service Worker による固定キャッシュは作らず、毎回の起動で CSS とゲーム JS（地形 JS 含む）のURLに変化をつけ、以前の版を使い続けないようにしています。公開CDNの配信反映には数分かかる場合があります。すでに開いている画面は閉じて再度開いてください。
- GitHub Pages が `main / (root)` に設定されていれば、main の更新は自動公開されます。Codexなどの作業ブランチだけを編集しても公開されず、mainへの統合が必要です。

## 公開を更新する

`dist/` がゲームの正本です。変更後に `npm run build` で単体HTML・アプリアイコン・manifestを生成し、`npm run check` で確認します。リポジトリ直下の `index.html` は `dist/index.html` へ移動する入口です。

GitHub Pagesは **main / (root)** から自動公開されています。作業ブランチだけを更新してもテストプレイURLには届きません。mainへの統合後、GitHubのPagesデプロイがそのコミットで成功し、公開画面の `nagi.release` が更新されたことを確認してください。共有先: https://hane-san.github.io/Koitototsukuru/

CSS・ゲームJS・地形JSは起動ごとの同じ更新パラメータで取得します。ホーム画面のアイコンは維持し、Service Workerによる固定キャッシュは使いません。

スマホは安全領域と動的ビューポートに対応し、短い縦画面・横画面でも開始ボタンと説明が重ならないよう配置しています。長押しによる選択・ドラッグ・コールアウト・プレイ中のピンチ操作を抑止し、画面切り替え・回転・タッチ中断で移動を解除します。

## 一本指の操作と研究

基本操作は一本指で完結します。左右は旋回、上下は前後移動で、斜め入力でも前進量を減らしません。横へ大きく滑らせてもカニ歩きへの切り替えはありません。キーボードのA/Dでは従来どおり横移動もできます。前進7.8、後退5.4、画角68度、挨拶開始4.8の設定です。視点の上下や頭の揺れは加えていません。

判断の根拠とユースケースは [docs/movement-research.md](docs/movement-research.md) を参照してください。

## 北側への拡張と操作の追加調整（2026-10-16）

- 歩ける面積は約2.4倍。新しい5つの景色は地続きでつながり、既存の浜・祠・鳥居・砂州も探索できます。祠の西脇から北へ進むと分岐に出ます。
- 横・縦それぞれのスライド幅を画面端からの距離で変えず、前進中は横方向の小さな指ぶれを吸収します。小さな速度調節と、その場での旋回もできます。
- 大きなスワイプで操作幅を越えた分だけ起点が追従し、長いスワイプ後も短く戻す操作に反応します。指を離せば即停止します。
- 衝突は移動ベクトル全体で判定し、斜めに触れた岩・木・海岸に沿って進みます。道の上に木・岩・島民を置かず、鳥居には正面から入れる道を引きました。
- 北側の植物を地域別に描画し、背後や遠いものを省きます。iPhone実機でのフレームレートは未計測です。
