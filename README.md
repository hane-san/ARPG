# 凪の島 — NAGI

淡く物悲しい瀬戸内の小さな島を歩く、一人称探索RPGの基本セットです。依存パッケージや外部CDNは使いません。WebGL対応のブラウザで動作します。

開発の入口：[AGENTS.md](AGENTS.md)（全AIの契約）・[開発手順](docs/DEVELOPMENT.md)・[設計索引](docs/DESIGN.md)・[採用判断](docs/DECISIONS.md)・[残課題](docs/ROADMAP.md)・[検証](docs/QA.md)。packageの現行版はv1.6.0。以下の版別更新記録は保持し、現在の移動基幹は末尾と [docs/movement-core.md](docs/movement-core.md) を参照します。

## 旅の余白の改善

基本はスマートフォンの縦持ちです。画面の下半分を一本指の操作に空け、地名・会話・小さな風景の文は上側に一つずつ表示します。島民のそばに立ち続けても、同じ挨拶で景色を遮りません。

右上のしおり（PCでは H）で立ち止まって、操作の再確認、音と字幕の切替ができます。閉じても押しっぱなしの入力では動き出しません。字幕を休めれば景色だけを眺められます。設定と発見は今回の旅の間だけで、再読み込みすると戻ります。

舟、ふたり分の椅子、取り込まれない布、海へ開く窓など、8か所に暮らしの跡を置きました。そちらを向いて少し立ち止まると、短い文が一度だけ現れます。地域ごとの地面の色、港の風に曲がった松、遠い岬の細い木々、草の茂みと積み石で道中の変化を増やしました。風車と海鳥が静かに動き、動きを減らす設定では止まります。

## 今回の更新（2026-10-18 / v1.5.0）

- 全速前進は7.8→14.4m/s（約1.85倍）、後退は7.2m/s。PCのShiftでは18m/s。指を少し上へ動かす歩行の速度域を残し、深く倒すほど加速します。停止・旋回・固定画角はそのままです。
- 東へ約700m拡張し、歩ける面積は約1.6倍（同じ4m間隔の地形サンプルによる比較）。道の総延長は約5.1km、地名は19→26か所になりました。
- 新しい景色は「潮を渡る石道」「水鏡の塩田」「葦と水路の庭」「風車の丘」「白灯台の岬」「海の図書室」「星砂の環」。塩の皿、水のある葦原、3基の風車、白い灯台、屋根のない柱廊と石の本、貝の環を配置しました。
- 元の東側の周回路から石道を渡り、東の島を一周して白い石切り場へ帰れます。塩田から戻れる近道もあります。島民は18人になり、行き先の手掛かりを話します。
- 速い移動でも小さな障害物を飛び越さないよう、長い移動を分割して衝突を調べます。新しい景色も地域ごとに描画を省く構成です。

## 起動

```sh
python3 -m http.server 4173 --directory dist
```

ブラウザで `http://localhost:4173` を開き、「島へ渡る」または Enter で開始します。

## 操作

- W / S（↑ / ↓）：前進 / 後退。後退時も同じ向きを保ちます。
- A / D：左右のカニ歩き。
- ← / → または Q / E：水平旋回。
- Shift：通常の走りから、さらに少し加速。
- マウス / タッチ：画面の下半分に指を置き、そこから上へスライドすると前進（全速で秒速14.4の走り）。下へスライドで後退、左右へのスライドは旋回、斜めへのスライドは曲がりながらの前進・後退になります。横へ動かした際にカニ歩きへ切り替わる動作はありません。置いただけでは移動せず、指を離すとすぐ停止します。スライド量で速度を調整できます。
- Escape / フォーカスを外す：入力を解除。

視線の上下操作・頭の揺れ・照準・移動ボタンはありません。必要なときだけ右上のしおりを開けます。島民に近づくと自動で挨拶します。音は開始操作の後に小さく流れます。足音は実際に進んだ距離と速度に合わせて交互に鳴り、砂・草・石で質感が変わります。停止・その場での旋回・障害物に押しつけた状態では足音は鳴りません。

## 島の構成

東には塩田・葦原・風車・灯台・海辺の遺構・星砂の浜をたどる周回路と近道があります。

オリーブの小径、潮見の鳥居、丘の祠、干潮の砂州、小さな離れ島に加え、北側へ薄紫の傘の森、花の尾根道、オリーブの段々畑、硝子の入江、空に近い岬を広げました。元の浜から北を一周して戻れる道と、入江への寄り道があります。能を思わせる面と衣をまとった18人の島民、淡い色の縞模様のキノコ、巻いたシダ、傘の形の大きな植物。地形は小豆島と瀬戸内から着想した架空の島です。

## 構造

- `dist/index.html`：開始画面と地名・挨拶の字幕。
- `dist/style.css`：全画面表示、淡い和文組版、開始後のUI非表示。
- `dist/island.js`：WebGL描画、手続き生成モデル、入力、衝突、島民、環境音。
- `dist/terrain.js`：地形・周回路・地名・地形頂点のキャッシュ。
- `dist/movement.js`：描画から独立した入力・継続加速・連続衝突検出・空間索引。
- `tests/terrain.test.js`：地形の接続・操作の数学的な検証。
- `tests/world-check.py`：北側の周回と入江への寄り道、配置物への衝突・景色の描画を検証。QA用アクセスは検証中のローカル応答にだけ挿入し、ゲームには含めません。
- `tests/browser-check.py`：Playwrightでの起動・移動・UI確認（任意、PlaywrightとChromiumが必要）。

```sh
npm run check
```

現段階は島を歩く基本セットです。戦闘、クエスト、セーブ機能はまだありません。

## 公開を更新する

`dist/` がゲームの正本です。変更後に `npm run build` で単体HTML・アプリアイコン・manifestを生成し、`npm run check` で確認します。リポジトリ直下の `index.html` は `dist/index.html` へ移動する入口です。

変更はIssue→作業ブランチ→PR→CI→リスク別の独立監査→人間の試遊・承認→mainの順に進めます。mainへの直接push・force-push・自動マージは行いません。手順と人間が設定するmain保護は [開発手順](docs/DEVELOPMENT.md) を参照してください。

GitHub Pagesは **main / (root)** から自動公開されています。作業ブランチだけを更新してもテストプレイURLには届きません。mainへの統合後、GitHubのPagesデプロイがそのコミットで成功し、公開画面の `nagi.release` が更新されたことを確認してください。共有先: https://hane-san.github.io/ARPG-01-SkyrimStyle/

CSS・ゲームJS・地形JSは起動ごとの同じ更新パラメータで取得し、Service Workerによる固定キャッシュは使いません。改名後のホーム画面は新URLで追加し直し、起動・操作・表示を確認してから旧アイコンを整理してください。

スマホは安全領域と動的ビューポートに対応し、短い縦画面・横画面でも開始ボタンと説明が重ならないよう配置しています。長押しによる選択・ドラッグ・コールアウト・プレイ中のピンチ操作を抑止し、画面切り替え・回転・タッチ中断で移動を解除します。

## 一本指の操作と研究

基本操作は一本指で完結します。左右は旋回、上下は前後移動で、斜め入力でも前進量を減らしません。横へ大きく滑らせてもカニ歩きへの切り替えはありません。キーボードのA/Dでは従来どおり横移動もできます。現在は前進最大14.4、後退7.2、画角68度、挨拶開始4.8の設定です。小さな入力は歩行、大きな入力で速く走ります。視点の上下や頭の揺れは加えていません。

判断の根拠とユースケースは [docs/movement-research.md](docs/movement-research.md) を参照してください。

## 北側への拡張と操作の追加調整（2026-10-16）

- 歩ける面積は約2.4倍。新しい5つの景色は地続きでつながり、既存の浜・祠・鳥居・砂州も探索できます。祠の西脇から北へ進むと分岐に出ます。

- 大きなスワイプで操作幅を越えた分だけ起点が追従し、長いスワイプ後も短く戻す操作に反応します。指を離せば即停止します。

## 広域の島と穏やかな操作（2026-10-17）

小豆島を思わせる港町・オリーブ・棚田・渓谷・石切り場を、長辺約960mの架空の島に凝縮しました。歩ける面積は前版の約47倍、広域の周回路は約2km。祠の西脇から北へ、元の岬を越えると広い島へ続きます。周回路に加え、渓谷を通る近道があります。

5つの巨大な幾何学作品（風環・空洞のピラミッド・天球・立方体・二重らせん）は固定した位置にあり、遠くからの目印になります。島民は11人になりました。作品の下・内部や道の中央は通れるように配置しています。

### 現在の一本指操作

- 下半分に指を置いた時点では停止。上へ7〜12 CSS pxほど動かし、そのまま保持すると歩き続けます。毎回こすり続ける必要はありません。
- さらに28〜36 pxほど上へ動かすと全速の7.8m/s。下は後退、横は常に旋回です。前後と旋回の操作幅を分け、小さな指ぶれで急旋回しにくくしました。
- 旋回の上限は静止時約72度/秒、全速移動時約54度/秒。回り始める際の加速も制限し、指を戻す・離すと即停止します。海岸に正面から当たったときも停止し、沿う方向へ入力したときは進めます。
- 固定60Hzの移動計算と描画補間で、フレーム間隔のばらつきを吸収します。カメラの高さは描画された地形と一致させ、停止後に上下へ追いつく遅れを取り除きました。上下視点・頭の揺れ・速度による画角変更はありません。

月は空の一方向にあり、カメラの向き・画角に合わせて投影します。180度振り返れば見えなくなり、一周すると同じ方向に戻ります。月の方向を回転後に正規化し、GPUの三角関数の丸め誤差による点滅も抑えています。遠い島・雲は世界内の位置に配置し、距離に応じて霞みます。

地形と道は同じ三角形に沿って描き、近い島は細かく、広域は粗い地形を使います。スマホの横方向の視野に入らない地形・植物・作品は描画から省きます。面積拡張に対して総頂点数の増加を抑えています。

## 移動基幹の整理（2026-10-18）

一本指のスライド操作と通常最高速14.4は維持。しっかり前進できている状態が約2秒続いた後、4秒ほどかけて最高16.2へ穏やかに上がります。短いスライドでの細かな歩行、後退、横歩き、その場の旋回、衝突中にはこの加速を溜めません。大きく曲がると上乗せ速度を滑らかに落とし、指を離す・中断する操作では即停止します。PCのShiftによる最高18は従来どおりです。

看板は幅12cmの支柱に半径4.5cmの判定を置き、灯籠・柱・樹木も見た目より小さめにしました。家・ベンチ・本の並びは複数の丸をやめ、少し内側の矩形で判定します。見えない判定の継ぎ目を減らし、面や角に沿って進めます。

近隣セルにある物体だけに連続衝突検出を行い、高速でも細い柱を飛び越えません。地形の高さは描画・移動・カメラで共用する静的頂点キャッシュに保存。CPU処理の繰り返しと毎フレームの一時オブジェクトを減らしました。高速時の足音も、実際の移動量を使いながら過密な連打にならない歩幅へ調整しています。

構造・変更時の注意点と検証方法は [docs/movement-core.md](docs/movement-core.md) を参照してください。追加の実タッチ検証は `python tests/controls-check.py` です。
