# 移動基幹

## 責務と不変条件

- `dist/movement.js` はDOM・WebGL・音声に依存しない。スライド量、入力の所有権、速度、移動量、接触を扱う。
- `dist/terrain.js` は静的な島の高さ、道、地名を持つ。移動とカメラの足元は、描画と同じ三角形を参照する。
- `dist/island.js` はイベントをつなぎ、固定60Hzの移動結果を描画と足音へ渡す。指を離す・中断する・画面を切り替えると同じ解除経路で停止する。
- 左右スライドは常に水平旋回。頭の揺れ、上下の視点、速度による画角変更は入れない。速度はカメラの向きへ回り、以前の向きへ滑る慣性を残さない。
- 足音は要求速度ではなく実際の移動距離を使う。停止・旋回だけ・衝突で動けない状態では足音を増やさない。

## 入力と加速

`GestureInput` は一つのポインターだけを所有する。二本目の指で操作を解除し、両方離すまで再開しない。ウィンドウのcaptureフェーズでpointerup/cancelを受け、キャンバス外の解除も処理する。capture喪失は入力全体をリセットする。マウスのbuttons=0も解除として扱う。

指を置いた直後の原点は中立。前後28〜36 CSS px、旋回64〜96 pxの幅と既存のデッドゾーンを維持する。大きなスワイプの越えた分だけ原点が追従する。pointermoveごとのレイアウト取得は行わない。

通常最高速14.4、継続加速後16.2。前進量75%以上・横歩きなし・強い旋回なし・十分な実前進・接触なしで約2秒を数え、その後4秒で滑らかに上げる。短い操作や後退は加速させない。強い旋回は上乗せを落とす。衝突や解除では蓄積を消す。Shiftの18とは重ねない。

## 形状と接触

`circleCollider(x,z,r,kind)` と `boxCollider(x,z,hx,hz,kind)` の寸法は**物体側だけ**。プレイヤー半径0.23を二重に足さない。判定はモデルより少し内側に置く。

| 対象 | 判定 |
| --- | --- |
| 看板 | 支柱だけ半径0.045。板は移動を遮らない |
| 灯籠 | 半径0.14 |
| 細い祠の柱 | 半径0.06 |
| 鳥居 | 半径0.14 |
| 島民 | 半径0.46 |
| 家 | 幅・奥行きの内側に置く矩形 |
| ベンチ、本、石切り場 | 見た目に合わせた少し小さな矩形 |

`CollisionWorld` はシーン生成後に一度作る静的なスナップショット。元の配列や物体を後から変更しても判定が食い違わないよう、コピーを固定する。物体の追加・移動を行う仕様では新しいworldを構築する。地形頂点も静的なので、動的地形を導入する場合は描画メッシュとキャッシュを一緒に再生成する。

8mセルの空間索引で候補を絞り、移動区間に対する最初の接触を求める。円と、角を丸めた矩形のスイープを使い、残りの移動量を接線へ投影する。最大4接触、接触面からの余白0.0002m。物体の登録順やワールドX/Zの判定順に依存した滑りを避ける。埋まった初期位置からは外へ出る入力を許し、カメラを押し戻すテレポートはしない。

海岸は最大0.18m間隔の確認と境界探索を使う。正面から当たれば止まり、十分に岸に沿う入力では滑れる。海岸への押しつけは継続加速を蓄積しない。

## 負荷と検証

地形頂点は約0.3MBのFloat64Arrayへキャッシュする。高さ自体は変更せず、同じ格子点で生成式を繰り返し計算しない。経路の固定配列も使い回す。視野判定の三角関数はフレームごとに一度だけ求め、カメラ履歴とNPCの描画オフセットも再利用する。

この作業環境で20,000回の高さ取得を比較し、既存版約160ms、キャッシュ温存後約4.2msだった。5,000地点の高さの一致も確認した。これは高さ取得処理の計測であり、端末のフレームレートやゲーム全体の高速化率ではない。

```sh
npm run build
npm run check
python tests/browser-check.py
python tests/controls-check.py
python tests/world-check.py
python tests/sky-check.py
```

単体検査は継続加速、衝突中の蓄積防止、逆入力、手動ダッシュ、柱のすり抜け防止、建物の面・角、複数接触、登録順、空間索引と全件探索の一致を含む。実タッチでは短い保持入力、加速窓、解除とcapture喪失からの復帰を確認する。周回検証は東側・近道も含めた実際の配置物を使う。テスト用アクセスはローカル応答にだけ追加し、配布物に含めない。
